# Shared case

`cavity.json` is read by both languages. Geometry is in meters, speed in m/s, time in seconds, diffusivity in m²/s, dynamic viscosity in Pa·s, and density in kg/m³ where applicable. Density documents Reynolds number; it is absent from steady Stokes momentum. The penalty coefficient is in Pa·s/m². Consult the tier README before modifying inputs.
